COMPLEXITY ANALYSIS

1. MERGE SORT

Time Complexity:
Best Case    : O(n log n)
Average Case : O(n log n)
Worst Case   : O(n log n)

Space Complexity:
O(n)

For n = 8 elements, the array is divided into smaller
subarrays and then merged. The number of merge operations
for this execution is 7.


2. QUICK SORT

Time Complexity:
Best Case    : O(n log n)
Average Case : O(n log n)
Worst Case   : O(n^2)

Space Complexity:
Average Case : O(log n)
Worst Case   : O(n)

In this program, the last element is selected as the pivot.
For the given input, 5 partition operations are performed.


COMPARISON

Merge Sort has a guaranteed O(n log n) worst-case time
complexity.

Quick Sort generally performs very well in practice, but
its worst-case time complexity can become O(n^2) depending
on pivot selection.

Merge Sort requires O(n) additional space, while Quick Sort
usually requires less additional space.
